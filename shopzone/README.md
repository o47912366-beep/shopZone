# ShopZone — React + Vite

Zamonaviy, responsive online do‘kon demo loyihasi.

## Imkoniyatlar
- Mahsulot qidirish, kategoriyalar bo‘yicha filtrlash va narx/reting bo‘yicha saralash
- Savatga qo‘shish, miqdorni o‘zgartirish, mahsulotni o‘chirish va jami summani hisoblash
- Sevimli mahsulotlar tugmasi
- Demo buyurtma formasi va mobil qurilmaga mos dizayn

## Ishga tushirish
```bash
npm install
npm run dev
```

Production build:
```bash
npm run build
```

## Vercel'ga joylash
1. `shopzone` papkasini alohida GitHub repository'ga yuklang.
2. Vercel'da **Add New → Project** orqali repository'ni import qiling.
3. Framework: Vite; Build command: `npm run build`; Output directory: `dist`.

**Eslatma:** bu frontend demo. To‘lov, haqiqiy buyurtma yuborish va server ma’lumotlar bazasi ulanmagan.
